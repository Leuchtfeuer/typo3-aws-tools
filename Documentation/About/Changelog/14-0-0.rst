===========================
Version 14.0.0 - 2026/05/05
===========================

* Add support for TYPO3 14
* Drop support for TYPO3 13
* Fix CDN rewriting skipped in eID context (e.g. tx_cms_showpic)

.. attention::

   **Breaking changes when upgrading from v13:**

   * The backend module has moved from the **Tools** section to the **System** section.
   * The extension TypoScript setup is now registered globally via ``addTypoScriptSetup()`` and
     no longer needs to be included manually through a TypoScript template record.

Download
========

Download this version from the `TYPO3 extension repository <https://extensions.typo3.org/extension/aws_tools/>`__ or from
`GitHub <https://github.com/Leuchtfeuer/typo3-aws-tools/releases/tag/v14.0.0>`__.
